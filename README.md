# kord – Design Prototype v2

Interactive HTML prototype za **kord** web app (B2B SaaS za upravljanje terenskom radnom snagom).

## Pregled

`index.html` je samostalni prototip koji sadrži:

- **Smjene** – Dan i Tjedan view, edit drawer
- **Nove smjene wizard** – 4 koraka (Osnovno, Cijene, Raspored, Pregled) + modali za Skeniranja i Zaposlenike
- **Predlošci** – lista s kartice i wizard za novi predložak
- **Lokacije / Zaposlenici / Događaji** – main pageovi i detalj tabovi
- Design sustav u skladu s Figma Design System fajlom (Inter font, Peach/Orange/Fog/Plum/Steel/Denim brand palete)

Nema build steppa — single-file HTML s inline CSS i vanilla JS.

## Pokretanje

Otvori `index.html` u browseru. Nije potreban server.
